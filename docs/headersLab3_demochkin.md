## Lab3-MarkdownLaTeX_demochkin
#### Markdown — это облегчённый язык разметки, созданный для форматирования текста с помощью простых символов и знаков препинания 
#### Используется для форматирования текста с помощью простых символов без применения сложных текстовых редакторов
#### Markdown нужен разработчикам для создания понятной, легковесной и легко читаемой документации, которая хранится прямо в коде и управляется системами контроля версий
